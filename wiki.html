支持

一个赛博终端风格的个人主页。首页是一个能敲命令的终端，里面还放着四模式 osu! 音游、Celeste 风格的平台跳跃加关卡编辑器、三个小游戏，以及可以把成绩打包搬到另一台设备的存档工具。

整站没有服务器程序。页面和脚本都是静态文件，成绩、成就、设置、自制关卡都保存在你自己的浏览器里，换设备时用「存档码」或分享链接手动搬运。

osu! 内核std / taiko / catch / mania，导入 .osz，回放可拖进度和倍速 Celeste 蔚蓝手感复刻，关卡编辑器，影子回放，分享链接 GameHub2048、贪吃蛇、扫雷，支持续局 音乐与贡献墙底部播放器、频谱、首页的 GitHub 贡献墙 存档码与分享打包、校验、合并，二维码，导入前先确认 终端命令26 条命令，⌘/Ctrl + K 打开命令面板

快速开始

本地预览

需要一个 http 服务。直接双击 index.html 不行，浏览器会拦截页面对各模块片段的读取。

cd loopzlx
python3 -m http.server 8770
# 浏览器打开 http://localhost:8770/load.html

部署

把整个文件夹上传到任何静态托管即可（GitHub Pages、Cloudflare Pages、Netlify、Nginx 都行）。部署时不需要安装 node，生成物已经在包里。

改了代码之后

npm install            # 只为 Tailwind，运行站点本身不需要
npm run build:all      # Tailwind 编译 + 版本号 + Service Worker + robots/sitemap
注意

没有样式、页面一片空白或模块打不开，先检查是不是用 file:// 打开的，再检查 css/tailwind.local.css 是否存在。

架构

整站只有一个真正的页面外壳 load.html。开机动画结束后跳到它，它负责加载样式和主页，并在你第一次打开某个模块时才去取该模块的片段和脚本。

  • 三个模块都是覆盖层：打开时页面锁定滚动，Esc 或左上角返回键关闭，不会跳转页面。
  • 所有数据在浏览器本地。站点自己的键以 lzx. 开头，其余按模块分前缀，完整清单见 存储键一览。
  • 外部依赖（音乐直链、Font Awesome 图标、GitHub 公开信息、osu! 镜像站）见隐私与外部依赖。它们不可用时对应功能降级，页面其余部分照常工作。

外观面板里还有三个开关：

  • MOTION：缩短 CSS 动画时长，减少动效。
  • LOW POWER：低功耗模式。停掉数字雨、贡献墙贪吃蛇和频谱这些 JS 驱动的循环，同时关闭毛玻璃和 CSS 动画。设置存在 lzx.lowpower，会随存档码同步。从未设置过时，只有系统开启了「省流量」才会自动开启。

音乐与贡献墙

底部播放器

首页往下滑，左下角会渐变出现播放器。歌单分为 SONGS、GAME MUSIC（Minecraft、Celeste OST、Strawberry Jam 三个文件夹）、PHONK、IDK、SYNTHWAVE 五组，共 44 首，支持上一首 / 下一首、音量滑块和频谱可视化。歌单写在 js/home/core/audio-player.js 里，改歌单只需编辑那份配置。

  • 音乐走外部直链（网盘解析），解析失败时会尝试备用链接（若该曲目配置了 alt）。
  • 打开 osu!、Celeste、GameHub 任一覆盖层时，底部播放器和频谱会收起。
  • 低功耗模式下频谱停止刷新。

GitHub 贡献墙

首页右栏有一块 GitHub 贡献墙，上面有一条自己游走的装饰蛇。它不是 GameHub 里的游戏，也不计分。桌面端全速运行，触屏和小屏封顶 30fps，低功耗模式下停止。

其他首页元素

  • 打字机标题和数字雨背景（/matrix）。
  • 技术栈占比（Stack Mix）：按站点自己的文件统计各语言体量。
  • 能力雷达图：Code / Design / Motion / Flow / Visual / Logic 六项。
  • 弹幕：终端里不带 / 的文字会飘过屏幕。

存档码与分享

数据只在浏览器里，所以换设备要手动搬。工具箱（/about 或 /save 打开）把成绩、成就、设置和自制关卡打包成一段文本。

导出与导入

  1. 旧设备：/save，选择要打包的内容，复制存档码或下载成文件。
  2. 新设备：/load，粘贴存档码，点「校验」，再点「导入并合并」。
  3. 导入前会弹出确认，列出将写入多少项、保留多少项本机更好的数据。刷新页面后生效。

分享链接与二维码

导出面板可以生成形如 https://你的域名/load.html#lzx=… 的链接，也可以显示二维码，用手机相机扫码打开。打开链接只会把内容预填并校验，不会自动写入，必须你点击确认。

格式

LZX1G-<base64url 数据>-<8 位十六进制校验>
LZX1G = gzip 压缩，LZX1R = 未压缩

校验位不对、前缀不对或版本高于当前支持的版本，都会在导入前被拒绝。

合并规则与范围

  • 取更优合并：最高分、最佳用时这类数据保留本机和存档里更好的一份，不是直接覆盖。
  • 只接受白名单键：存档码里不在清单内的键一律忽略，值必须是字符串。
  • 体积较大的可选项（默认勾选）：Celeste 自制关卡、图库、影子，osu 榜单、回放。
  • 音乐源和外部接口的数据不属于存档。

离线与性能

Service Worker

  • 首次访问后预缓存全站 69 个静态文件，所以断网也能打开主页、osu!、Celeste 和 GameHub。音乐直链和图标字体需要联网。
  • 代码文件（html / js / css / json）走网络优先，断网才回落到缓存，所以改了代码刷新就能看到。
  • 图片和字体走缓存优先。
  • 缓存名是 lzx-v<版本号>，升级版本会清掉旧缓存。匹配时忽略 ?v= 查询串。
  • 跨域请求（音乐、CDN）不经过缓存。

性能

  • 背景透视网格只用 transform 做动画，不触发重绘。
  • 贡献墙的蛇桌面端全速运行，触屏和小屏封顶 30fps，关闭时降到很低的刷新率。
  • 手机端去掉 backdrop-filter。
  • 覆盖层打开时，底层页面的动画循环会暂停。
  • 仍然卡顿时，打开外观面板的 LOW POWER。

隐私与外部依赖

  • 没有账号、没有后端、没有统计脚本。成绩、成就、设置只在你的浏览器里。
  • 浏览器会向这些外部地址发请求：音乐直链、Font Awesome（cdnjs）图标字体、GitHub 公开仓库信息（ungh.cc / api.github.com，用于首页「最近提交」一行）、osu! 谱面镜像站（仅在你搜索下载时）。
  • 这些不可用时对应功能降级，其余部分照常使用。
  • 存档码和分享链接里只有白名单键的数据，不含账号或设备标识（lzx.uid 是随机生成的本地访客号）。

构建与测试

版本号与域名

只改 version.json：

{ "version": "7.3.0", "siteUrl": "https://loopzlx.github.io/" }

再运行 npm run build。它会统一 load.html 和各 loader 里的 ?v=、重新生成 sw.js 和预缓存清单、同步 og / canonical，并按域名生成 robots.txt 与 sitemap.xml。

Tailwind

站点不再使用 CDN 版 Tailwind。新增或改动了 html / js 里的 Tailwind 类名之后，运行 npm run build:css，生成 css/tailwind.local.css。

回归测试

bash tests/run.sh
PORT=8771 CHROMIUM=/path/to/chrome OUT_DIR=./out bash tests/run.sh

依赖 python3 和 playwright。先对所有 JS 做语法检查，再按编号运行 12 个脚本：冒烟、外壳、关卡编辑器、影子、Celeste、实际游玩、工具箱、回放、回放控制、分享链接、判定与分区记忆、站点百科窗口。任何一项失败，整体退出码非 0。

CI 在 .github/workflows/test.yml：每次提交和 PR 自动构建并跑全部回归，并检查生成物是否已提交。

安全约定

  • 来自存档码、分享链接、导入文件（.osz 等）或外部接口的字符串，写入 innerHTML 前必须转义（各文件里的 esc()）。能用 textContent 就用 textContent。
  • 不使用 eval 或 new Function 执行导入的内容。
  • 存档码导入只接受白名单键，分享链接只预填、不自动写入。

常见问题

双击 index.html 打开是空白或缺模块

页面要用 fetch 读取各个片段，浏览器会拦截 file:// 下的读取。请用 python3 -m http.server 之类的 http 服务打开。

页面没有样式，排版全乱

检查 css/tailwind.local.css 是否存在且被 load.html 引用。缺失时运行 npm run build:css。

我改了代码，刷新后还是旧的

代码文件是网络优先，通常刷新即可。若仍是旧的，在浏览器开发者工具的 Application 里注销 Service Worker 并清除站点数据，或者升高 version.json 的版本后重新构建。

Market 行情去哪了

v7.1.0 起已移除。导航、命令面板、精选作品里的入口都删了，/warp market 不再可用。旧存档码里的 mk.* 数据导入时会被忽略。

音乐不响或播放器提示解析失败

音乐走外部直链，播放器解析失败时会回退到直链再试。链接失效属于外部来源的问题，不影响其余功能。

换了设备成绩没了

数据只在原浏览器里。在原设备上用 /save 导出存档码，到新设备用 /load 导入。详见存档码与分享。

按数字键 4 没反应

移除 Market 后数字键改为 1 osu!、2 gamehub、3 celeste。

想关掉所有动画省电

打开外观面板，开启 LOW POWER。它会停掉数字雨、贡献墙蛇和频谱，并关闭毛玻璃与 CSS 动画。

导入存档码提示格式不对

存档码必须以 LZX1G- 或 LZX1R- 开头，并以 8 位校验结尾，中间不能被换行或空格截断。复制时要完整。
